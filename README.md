# Reach Lab by RSM

![Reach Lab by RSM](brand/wordmark.png)

A graffiti handstyle practice app: real pens, inks and surfaces, in your browser.

**Open it:** https://raw.githack.com/nikbennett26-cpu/reach-lab/main/index.html

On a phone or iPad, open the link in Safari or Chrome, then **Share → Add to Home Screen** to run it full screen like an app. Tilt (chrome shine, Future Juice, drips) uses the device's motion sensor — allow it when asked.
